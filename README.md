# Project 3 iterations

## Run it
1. Install Node.js (version 18 or newer) if you don't have it.
2. In this folder, run:
   npm install
   npm start
3. The page opens at http://localhost:3000

## Add your links
Open `src/iterations.js` and replace `"#"` with your URL. Copy a line to add another version.

## Keepers
`public/keepers.html` is the Keepers prototype. It opens at http://localhost:3000/keepers.html.
Run locally, it works in single-device mode (use "Side by side" to demo both phones).
The shared two-phone version lives at https://claude.ai/artifact/U7wWPhgqJRRFVd1h8JyT8J
